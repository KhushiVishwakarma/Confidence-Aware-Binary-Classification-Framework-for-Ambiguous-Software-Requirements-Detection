# Dataset

This directory contains the PURE software-requirements ambiguity dataset
used in the experiments.

The dataset is derived from the replication package:

https://github.com/profzivkovic/software-requirements-ambiguity-detection-replication

The original replication repository provides `pure_labeled.csv` under
its `data/` directory and is distributed under the MIT License.

This repository uses the dataset for the experiments reported in the
associated ICCTRDA 2026 paper.
